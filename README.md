# راهنمای اجرای پروژه رزومینو (Resumino) با داکر

این پروژه به طور کامل داکرایز شده است و شما می‌توانید بدون نیاز به نصب پایتون یا پکیج‌های اضافی، پروژه را تنها با دو دستور اجرا کنید.

---

## 🚀 راه‌اندازی سریع (در ۳ مرحله ساده)

### مرحله ۱: ساخت فایل محیطی (`.env`)
ابتدا فایل نمونه را کپی کنید تا فایل `.env` ساخته شود:

```bash
cp .env.example .env
```
*(در ویندوز می‌توانید فایل `.env.example` را کپی کرده و نام آن را به `.env` تغییر دهید)*.

> **نکته:** در صورتی که نیاز به استفاده از قابلیت‌های هوش مصنوعی دارید، مقدار `API_KEY` را در فایل `.env` با کلید Groq خود پر کنید.

---

### مرحله ۲: بیلد و اجرای پروژه
دستور زیر را در ترمینال (مسیر اصلی پروژه) اجرا کنید:

```bash
docker compose up --build
```

با این دستور:
1. ایمیج پروژه ساخته می‌شود.
2. وابستگی‌ها نصب می‌گردند.
3. مایگریشن‌های دیتابیس (`migrate`) به صورت خودکار اعمال می‌شوند.
4. سرور جنگو بالا می‌آید.

---

### مرحله ۳: مشاهده پروژه در مرورگر
مرورگر خود را باز کنید و آدرس زیر را وارد نمایید:

👉 **[http://localhost:8000](http://localhost:8000)**

پنل ادمین نیز در آدرس زیر در دسترس است:  
👉 **[http://localhost:8000/admin](http://localhost:8000/admin)**

---

## 🛠 دستورات کاربردی

### ۱. اجرای پروژه در پس‌زمینه (Background)
اگر نمی‌خواهید ترمینال درگیر بماند:
```bash
docker compose up -d
```

### ۲. خاموش و متوقف کردن کانتینرها
```bash
docker compose down
```

### ۳. ساخت کاربر ادمین (Superuser)
برای ساخت حساب کاربری مدیر جنگو:
```bash
docker compose exec web python manage.py createsuperuser
```

### ۴. مشاهده لاگ‌های زنده پروژه
```bash
docker compose logs -f
```

---

## ⚠️ نکته مهم برای اجرای پروژه در ایران (رفع تحریم داکر)

در صورتی که موقع بیلد اولیه با خطای **403 Forbidden** مواجه شدید (به دلیل تحریم‌های Docker Hub)، یکی از دو راه زیر را انجام دهید:

1. **تنظیم DNS شکن روی سیستم:**
   - دی‌ان‌اس اول: `178.22.122.100`
   - دی‌ان‌اس دوم: `185.51.200.2`
2. یا استفاده از ابزارهای رفع تحریم (مانند الکترو، شکن یا اجرای تحریم‌شکن روی سیستم).
